# **Loan Approval Prediction Model :-** 

A beginner-friendly Machine Learning project that predicts whether a loan application will be approved using Random Forest Classification.

📌 **Project Overview :-**

This project predicts loan approval based on applicant and loan-related features such as :
* Income
* Education
* Credit history
* Property area

🛠️ **Technologies Used :-**

* Python
* Pandas
* Scikit-learn
* Random Forest Classification

🔍 **Steps :-**

1. Load the loan dataset.
2. Handle missing values.
3. Encode categorical data.
4. Split the data into training and testing sets.
5. Train the Random Forest model.
6. Predict loan approval.
7. Evaluate the model using accuracy.

📊 **Output :-**

* Prediction Accuracy
* Loan Approval Prediction

🎯 **Learning Outcome :-**

This project helped me to learn data preprocessing, categorical encoding, classification, model training, prediction, and evaluation using Random Forest Classification.
